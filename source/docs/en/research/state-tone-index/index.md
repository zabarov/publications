# State Tone Index

The State Tone Index is a conceptual-methodological research project that explores how macro-social affective climate and institutional-emotional conditions may be represented through a transparent multidimensional framework.

## Current Status

Working paper v0.1 is in internal draft status. It is not yet a validated index and should not be used as a country diagnosis or policy claim.

## Planned Public Materials

- Working paper PDF.
- Data/code release package.
- Construct map.
- Evidence and indicator tables.

## Research Boundary

The current v0.1 pilot is exploratory, non-validated and proxy-based. It does not directly measure emotional climate.
