# Approved Technology Chain

This fixture evaluates planning, not source-code generation.

## Steps

1. Confirm package boundary.
2. Extract required features and constraints.
3. Activate graph context.
4. Select implementation order.
5. Identify blocked alternatives.
6. Define tests and evidence.
7. Classify assumptions and risks.
8. Produce Dynamic Episode trace.
9. Route findings to fix, test gap, spec gap, graph proposal, process
   improvement, blocker or deferral.

## Required Boundaries

- Do not propose files outside the fixture package.
- Do not add password reset or user registration work.
- Do not expose token secret material after creation.
- Do not treat the trace as canonical graph mutation.
- Do not claim real code-generation improvement from this fixture.
