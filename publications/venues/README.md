# Publication Venues

This registry tracks where articles may be published, in which language and for
which role. The canonical archive remains this repository unless a specific
academic or editorial venue becomes the canonical version of record.

## Current Venue Map

| Venue | Language | Role |
| --- | --- | --- |
| Habr | Russian | Primary Russian technical audience for practical articles and retrospectives. |
| Medium | English | International longform essays and cross-posted English editions. |
| Hashnode | English | Developer-focused technical blog with markdown/GitHub-oriented workflow. |
| DEV Community | English | Shorter practical developer articles and implementation notes. |
| InfoQ | English | Selective professional software-development outlet for mature articles. |
| ACM Queue | English | High-bar professional software engineering venue for refined essays. |
| SSRN | English | Research preprints and working papers. |

## Cross-Posting Policy

- Keep the repository as the public metadata archive.
- Use canonical links where the target platform supports them.
- Keep Russian Habr editions native to Habr rather than literal translations.
- Publish English editions only after public-safety review and terminology
  cleanup.
- Do not publish private SIMAI data, raw logs, credentials, internal prompts,
  customer context or unpublished scientific claims.

The structured registry is maintained in `data/publication-venues.yml`.
