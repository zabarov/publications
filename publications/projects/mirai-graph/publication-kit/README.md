# Mirai Graph Publication Kit

This package prepares the first public Mirai Graph article.

The material is a public-safe draft. It explains Mirai Graph through one
practical workflow instead of trying to introduce the whole standard at once.

## Materials

- [Introductory article draft](introductory-article/)

## Selected Workflow

The selected workflow is the implementation-control loop:

```text
seed -> graph -> context -> launch -> transition explanation -> evidence -> feedback -> kaizen
```

This workflow was selected because it shows the core Mirai Graph idea in a
practical way:

- graph state gives context;
- launch records bound work;
- process transitions are checked;
- evidence supports decisions;
- feedback stays separate from canonical updates.
