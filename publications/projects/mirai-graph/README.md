# Mirai Graph

Mirai Graph is an evolutionary graph operating model for managing the growth of
complex systems.

Repository: <https://github.com/zabarov/mirai-graph>

## Current Result

The project already has a public alpha repository with:

- standard sections;
- schemas;
- examples;
- profiles;
- pilots;
- release notes;
- CLI validation commands;
- citation metadata.

In simple terms, Mirai Graph describes how a complex AI-assisted system can keep
state, evidence, readiness and control rules in an explicit graph instead of
spreading them across chats, documents and disconnected task notes.

## What It Gives

Mirai Graph gives a practical model for governed AI work:

- objects describe the current state of the system;
- relations show dependencies;
- evidence connects claims to sources;
- readiness shows maturity and uncertainty;
- gates separate suggestions, decisions and actions;
- context packs give AI tools the right task-specific context.

This is useful for AI skills, project control, human-AI workflows, organizational
governance and research programs where losing context becomes expensive.

## Public Boundary

Public:

- the model;
- standard sections;
- schemas;
- synthetic examples;
- profiles;
- public-safe pilots;
- reproducibility notes;
- citation metadata.

Private or out of scope:

- private SIMAI routes;
- raw skill sources;
- internal logs;
- customer data;
- credentials;
- unpublished scientific claims.

## Next Goal

The next goal is a focused public introduction to Mirai Graph.

Done means:

- one practical workflow is selected as the main explanation path;
- the article explains graph state, evidence, readiness and gates through that
  workflow;
- the text avoids private implementation details;
- claims stay within the public alpha boundary;
- the article links to a stable repository release or release candidate.

This goal connects directly to the final result: Mirai Graph should be
understandable as a practical operating model before readers are asked to study
the whole standard.
